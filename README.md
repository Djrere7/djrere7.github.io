# First Spin DJ Bootcamp — Website

A modern, mobile-first, **multi-page static site** for **firstspindjbootcamp.org**.
First Spin DJ Bootcamp is a nonprofit educational initiative of **MixHer Inc.**, a 501(c)(3).

No build tooling required to serve it — it's plain static HTML/CSS/JS. Deploy the
folder to any static host (Cloudflare Pages, Netlify, GitHub Pages). Preview locally:
`python3 -m http.server` then open http://localhost:8000/.

## Architecture
- **Shared** `styles.css` + `main.js` — one design system + one behavior file for every page.
- Brand fonts: **Bangers** (display) + **Montserrat** (body), via Google Fonts.
- Palette: Teal `#12B3B8` · Orange `#FF7900` · Black `#02090A` · Cream `#F4EFE9` · Dark Teal `#008E93` · Silver `#A7A7A7`.
- All links/assets are **root-relative** (`/styles.css`, `/img/…`, `/miami-dj-bootcamp/`), so pages work at any depth **on the apex domain**.

## Pages
`/` (home) · `/summer-2027/` · `/miami-dj-bootcamp/` · `/broward-dj-bootcamp/` ·
`/for-parents/` · `/impact/` · `/about/` · `/sponsors/` · `/donate/` · `/host/` ·
`/contact/` · `/news/` · `/thank-you/` · `/privacy/` · `/accessibility/` · `/404.html`

Home, Miami and Broward are hand-authored. The rest are generated by
**`build/generate.py`** (run `python3 build/generate.py` from the site root to
regenerate after editing that file). Editing a generated page's HTML directly also
works, but re-running the generator overwrites it.

## Set these before launch — `main.js` → `window.FIRST_SPIN_CONFIG`
- `interestFormUrl` — approved Google Form URL. Every "Join the 2027 Interest List"
  button opens it. Until set, buttons scroll to the on-page short interest form,
  which submits via `formEndpoint` (or opens a prefilled email fallback).
- `donateUrl` — MixHer Inc. donation link (First Spin designation).
- `newsletterUrl` — email-platform signup (optional).
- `formEndpoint` — Formspree (or similar) endpoint for interest/sponsor/venue/contact forms.
- `ga4MeasurementId` — GA4 `G-XXXX` (events also push to `dataLayer` for GTM).

## Confirmed content rules (baked in)
- **Ages 7+** everywhere. Parents/guardians complete all forms; children make no accounts.
- **Summer 2027 | June–August** with **"Exact Dates Coming Soon"** — never invent exact dates.
- Two 2027 markets: **Miami-Dade** and **Broward** — each with its own SEO page; both marked
  **"2027 Location Being Finalized"** until a venue is confirmed.
- Fundraising leads with **cash operating support** (not equipment).
- Nonprofit language: *"a nonprofit educational initiative of MixHer Inc., a 501(c)(3)."*
  Donations: *"Contributions to MixHer Inc. designated for First Spin DJ Bootcamp are
  tax-deductible to the extent permitted by law."* (never "fully tax-deductible").

## ⚠️ Needs First Spin approval — search `[NEEDS FIRST SPIN APPROVAL]`

  and marked "recognition announced once approved." Publish the name + logo + exact
